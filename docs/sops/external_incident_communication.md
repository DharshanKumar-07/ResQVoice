# External Incident Communication

Use this runbook before sending customer, regulator, press, or other external
incident communication.

## Required steps

1. Confirm the incident facts, affected audience, impact window, and current mitigation status.
2. Separate verified facts from hypotheses and remove secrets, personal data, and unsupported claims.
3. Draft the external message using the approved incident communication template.
4. Obtain explicit approval from the Incident Commander and Communications owner and record both reviewers.
5. Send the approved message through the authorized external communication channel.
6. Verify successful delivery and capture the published message and timestamp.
7. Record feedback, corrections, and the next scheduled update in the incident timeline.
