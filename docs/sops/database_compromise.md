# Suspected Database Compromise

Use this runbook for suspected unauthorized database access, credential theft, or data exfiltration.

## Required steps

1. Preserve database audit logs, access logs, and volatile forensic evidence.
2. Confirm the affected database, accounts, data classes, and suspected compromise window.
3. Restrict access using a reversible containment plan without destroying evidence.
4. Trigger the security escalation and obtain explicit Incident Commander approval for containment.
5. Rotate exposed credentials and isolate compromised identities or hosts.
6. Verify legitimate application access, replication health, and audit-log continuity.
7. Record findings and initiate the approved external incident communication process if required.
